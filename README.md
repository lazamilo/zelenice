# Zelenice redesign

Pitch redesign of [zelenice.si](https://www.zelenice.si) (Javno podjetje Zelenice d.o.o., Celje): a static, clickable site built from the client's own copy, logo and photography.

## Pages

`site/` holds the finished site (plain HTML, no build step needed to view it):

- `index.html`: hero, mission statement, seven activities, "Mesto skozi vse leto" seasons scroll, projects, facts, cemeteries, news, contact
- `o-podjetju.html`, `dejavnosti.html`, `projekti.html`, `aktualno.html`, `kontakt.html`
- `pogrebne-storitve.html`: the navy funeral and cemetery sub-site

## Run locally

```bash
cd site && python3 -m http.server 4910
```

Then open http://localhost:4910.

## Editing

Pages are generated by `build.py` from shared templates (header, mega menu, footer) and the content data at the top of the file. Edit there, then:

```bash
python3 build.py
```

Styles are in `site/assets/css/style.css` and interactions in `site/assets/js/main.js` (GSAP + ScrollTrigger + Lenis, vendored in `site/assets/js/vendor/`).

## Hero video

The hero plays `site/assets/video/hero-1.mp4` to `hero-7.mp4` in sequence and falls back to the photo slideshow when they're missing. To add clips, put the source files in `source/video/` (named in play order) and run:

```bash
sh encode-video.sh
```

It trims 3.4 s from each clip and encodes 1080p H.264 with macOS's built-in `avconvert`.

## Stack

- Type: Switzer (Fontshare), self-hosted in `site/assets/fonts/`
- Brand colours: green `#1b826f`, lime `#c2e395`, navy `#0d3862`
- Logo: client's official SVG, unmodified
